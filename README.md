# StudyAgent 学习刷题 Agent 平台

在自己电脑上运行的学习与刷题平台。先学课程再做题，题目按难度分层，自动排学习计划，错题按间隔复习，按时生成周测月测。可以接入各家大模型，用智能体讲题、规划和分析薄弱点。电脑是独立窗口程序，手机用 App 连接，数据互通。

第一个内置学科是「编程机考」：

- 46 道真题，含 491 个隐藏测试用例和已校验的参考解；
- 力扣热题 100；
- 11 个模块的课程。

框架是通用的，可以新建任何学科并导入题目。

## 下载

到 **[Releases](../../releases/latest)** 下载最新版：

| 文件 | 说明 |
| --- | --- |
| `StudyAgent.exe` | Windows 程序，双击运行，不需要安装 Python |
| `StudyAgent.apk` | 安卓 App，连接电脑上的 StudyAgent 使用 |

每次推送到 `main`，GitHub Actions 会自动测试、打包并更新这两个文件。

## 从源码运行

需要 Python 3.9 及以上。

```
pip install -r requirements.txt
python run.py
```

浏览器会自动打开网址 ，本机免登录。

自己打包桌面程序：

| 系统 | 命令 | 生成 |
| --- | --- | --- |
| Windows | 双击 `build_windows.bat` | `dist\StudyAgent.exe` |
| macOS | `sh build_mac.sh` | `dist/StudyAgent.app` |

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 课程 | 每个模块按「概念 → 识别信号 → 模板 → 例题 → 易错点 → 小测验」讲解，学完再练 |
| 题库 | 单选、多选、判断、填空、简答、编程、外部题；L1 入门 → L4 挑战四个层级 |
| 判题 | 编程题在本机运行，按隐藏用例通过率给分，力扣核心代码模式 |
| 计划 | 按考试日期和每天时间排到每一天；时间不够时报告缺口，由你选择处理方式 |
| 错题 | 自动收录，按 1、3、7、14 天间隔复习 |
| 测试 | 周测、月测、自定义、AI 出题；服务器计时，断线恢复，到时自动交卷，可复核 |
| 智能体 | 学习助教、规划师、考前教练；要改数据时先给建议，你确认后才生效 |
| 模型 | DeepSeek、通义千问、Kimi、智谱、OpenAI、Claude、本地模型；按任务指定模型，记录用量 |
| 导入 | PDF、Word、文本、CSV、JSON；模型拆题、分类、分层，检查后才入库 |
| 多设备 | 手机 App 和其它电脑通过局域网访问同一份数据 |

## 注意

- 数据保存在你自己的电脑上。打开「允许手机连接」后，同一网络里拿到访问码的人可以在你电脑上运行编程题代码，只在可信的网络里开启。
- 内置题目来自机考真题整理和力扣题目链接，仅供个人学习。
