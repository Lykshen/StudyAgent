## 1. 安装

### 方式一：下载打包好的程序（推荐）

打开仓库的 **Releases** 页面，在「StudyAgent 最新版」下面下载：

| 文件 | 用在哪 | 怎么装 |
| --- | --- | --- |
| `StudyAgent.exe` | Windows 电脑 | 放在任意文件夹，双击运行。不需要安装 Python |
| `StudyAgent.apk` | 安卓手机 | 下载后点开安装。手机会提示「未知来源」，允许一次即可 |

> Windows 第一次运行 exe 时，SmartScreen 可能提示「已保护你的电脑」，点「更多信息 → 仍要运行」。这是因为程序没有购买代码签名证书，不是病毒提示。

每次推送代码到 `main`，GitHub 会自动重新打包并更新这两个文件（见仓库的 **Actions** 页）。

### 方式二：自己打包

| 系统 | 操作 | 结果 |
| --- | --- | --- |
| Windows | 双击 `build_windows.bat` | `dist\StudyAgent.exe` |
| macOS | 终端运行 `sh build_mac.sh` | `dist/StudyAgent.app` |
| 安卓 | 见 [mobile/README.md](../mobile/README.md) | `app-debug.apk` |

需要先装 Python 3.9 以上（安装时勾选 Add to PATH）。第一次打包要联网下载依赖，大约 3–5 分钟。

### 方式三：直接从源码运行

```
pip install -r requirements.txt
python run.py
```

Windows 可以双击 `start_windows.bat`，macOS / Linux 运行 `sh start_mac_linux.sh`。启动后浏览器自动打开 http://127.0.0.1:8765 。

### 数据存在哪

| 运行方式 | 数据位置 |
| --- | --- |
| Windows exe | `%APPDATA%\StudyAgent` |
| macOS app | `~/Library/Application Support/StudyAgent` |
| 源码运行 | 项目里的 `data/` 文件夹，或 `--data` 指定的目录 |

换新版本的 exe、删除 exe，都不会动这个文件夹里的数据。

## 2. 第一次使用

1. **打开程序。** 在这台电脑上会自动登录，不用密码。
2. **添加一个模型**（可以晚点做）。到「模型」页面选服务商、填 API Key、点「测试连接」。没有模型时，做题、判分、计划、测试都能用，只是智能体、AI 讲解、AI 出题和导入题目用不了。详见 [第 8 节](#8-接入模型)。
3. **设定学习目标。** 到「学习计划」，填：
   - 考试日期、每天能学几个小时；
   - 周测安排在星期几、月测安排在每月几号；
   - 错题复习间隔（默认 1、3、7、14 天）；
   - 编程语言（编程类学科）。

   保存后会自动排出每天的任务。
4. **回到「总览」开始今天的任务。**

## 3. 每天怎么学

「总览」页显示今天的任务、逾期任务、待复习的错题和本周进度。

每个模块都按 **先学、后练** 的顺序安排：

1. **学习课程。** 计划里先出现模块的课程。课程依次讲：
   - 核心概念；
   - 题目里出现哪些信号时该用这个方法；
   - 代码模板；
   - 一道例题；
   - 常见错误；
   - 小测验。

   读完点「学完了」，再开始做这个模块的题。
2. **做题。** 同一模块里，题目按难度层级从简单到难排：

   | 层级 | 含义 |
   | --- | --- |
   | L1 入门 | 单一知识点，按题意直接实现 |
   | L2 基础 | 套用一个标准方法或模板 |
   | L3 进阶 | 组合两种方法，或边界、规则较复杂 |
   | L4 挑战 | 综合性强，需要较深的分析或设计 |

   L4 默认不排进计划，想练可以在「学习计划」里勾选「包含挑战题」。
3. **复习错题。** 到期的错题会出现在「总览」和「错题复习」。
4. **考前冲刺。** 学习期在 14 天以上时，最后约 15% 的天数是冲刺期：不再安排新内容，用来补漏和复习。

### 时间不够怎么办

如果所有任务加起来超过你给的时间，「学习计划」顶部会显示差多少分钟，让你选一种处理方式。平台不会悄悄多塞任务。

| 选项 | 效果 |
| --- | --- |
| 缩小范围 | 从最难、最费时的题开始去掉，已校验的核心题保留 |
| 推迟考试日期 | 把考试日期往后挪 |
| 增加每天时间 | 页面会给出建议的每日小时数 |

### 逾期任务

过了日期还没完成的题不会消失，会列在「逾期任务」里。你可以：

- 点「全部从今天起重新排期」，把没做完的题顺延；
- 对某道题点「跳过」，以后不再排进计划。跳过的题在题库里筛选「已跳过」可以恢复。

## 4. 做题与判分

「题库」可以按模块、层级、题型、状态筛选，也可以按关键字搜索。题目页下方的 AI 按钮：

| 按钮 | 给你什么 |
| --- | --- |
| 给我提示 | 只给思路方向，不给答案 |
| 完整解析 | 思路、关键步骤、复杂度、常见错误 |
| 检查我的作答 | 看你写的代码或答案哪里有问题 |
| 讲讲知识点 | 讲这道题用到的方法 |
| 出一道相似题 | 换个情境出一道同类题练手 |
| 补充边界用例 | （编程题）列出容易漏掉的边界情况 |

用过提示、看过解析或参考答案，这次作答就不算独立完成。「独立通过率」只统计没用过这些帮助的作答。

### 判分规则

| 题型 | 规则 |
| --- | --- |
| 单选、判断 | 对就得分 |
| 多选 | 全对才得分，漏选或错选都不得分 |
| 填空 | 按空计分。每个空可以有多个正确写法，默认不区分大小写、忽略空格，题目会写明规则 |
| 简答 | AI 按评分要点打分，并给出依据和缺了哪些要点。测试里的分数可以填写理由复核修改 |
| 编程 | 在你电脑上运行代码，按通过的测试用例比例得分（含隐藏用例） |
| 外部题（如力扣链接） | 去原网站做，回来手动标记完成 |

### 编程题

- 写法和力扣一样，叫 **核心代码模式**：只写 `def solve(...)` 函数，或 `class Solution`，不用自己处理输入输出。
- 常用库已经导入，可以直接用 `Counter`、`defaultdict`、`deque`、`heapq`、`bisect`、`lru_cache`、`List`、`math`、`re` 等，和力扣一致。
- 「运行样例」只跑题目里给出的样例，「提交」会跑样例加全部隐藏用例。
- 结果说明：

  | 结果 | 含义 |
  | --- | --- |
  | 通过 | 这个用例答对了 |
  | 答案错误 | 输出和期望不同 |
  | 运行错误 | 程序抛了异常 |
  | 超时 | 超过时间限制 |
  | 未运行 | 前一个用例超时，后面的就不跑了 |
- 支持 Python。电脑装了 Node.js 时也支持 JavaScript。Java、C++ 暂时只能用「检查我的解法」让 AI 看。

### 题目有错

题目页底部「题目有问题？」，选择「答案错误 / 解析不清 / 题意不完整 / 其它」，写明情况后点「反馈」。

## 5. 错题复习

- 答错、没拿满分的题自动加入错题本。外部题（力扣链接）没把握时点「需复习」，也会加入。
- 复习按间隔进行，默认 1、3、7、14 天：
  - 到期当天重做并拿满分，进入下一轮；
  - 没满分，从第一轮重来；
  - 没到期时重做不算一次复习；
  - 全部轮次都通过，这道题就算掌握了。
- 在题目页可以给错题打「错因标签」、写「我的笔记」。「错题复习」页列出每道题的轮次、下次复习日期、错因和历次复习结果（✓ / ✗）。
- 已经掌握的题可以点「移出错题本」。
- 间隔可以在「学习计划」里改。

## 6. 周测、月测和自定义测试

### 自动安排的测试

周测和月测按你在「学习计划」里选的日期出现：

- 月测选了 31 号，遇到没有 31 号的月份，就在那个月的最后一天。
- 考试前一天固定安排一次月测，当作全真模拟。
- 到期的测试出现在「总览」和「测试」页，可以开始，也可以跳过这一次。

### 组卷

组卷按学科的考试结构来。编程机考是：

| 项目 | 内容 |
| --- | --- |
| 题量 | 3 道 |
| 分值 | 100 + 100 + 200 |
| 及格 / 优秀 | 150 分 / 300 分 |
| 时长 | 150 分钟 |

- 默认只从已经学过的模块里出题，并避开最近 14 天做过的题。
- 题不够时，平台会列出缺哪类题，让你改条件（比如允许出最近做过的题），不会悄悄降低要求。
- 也可以选「AI 出题」，由模型按考试结构现出一套新题。

### 考试中

- 倒计时以服务器时间为准，刷新页面或关掉再打开，答案和剩余时间都会恢复。
- 答案自动保存。可以标记「待检查」。
- 考试期间不显示标准答案，智能体和 AI 讲解都关闭。
- 时间到自动交卷。重复点交卷只会算一次成绩。

### 考试后

- 报告显示总分、每题得分和用时、各知识点表现。
- 错题自动进入错题本，并给出后续复习建议。
- AI 评的分会标明。觉得判错了，可以填写理由调整分数，原分数和调整记录都会保留。

## 7. 智能体

「智能体」页有三个助手：

| 智能体 | 适合做什么 |
| --- | --- |
| 学习助教 | 讲题、答疑、出练习题考你、推荐视频、根据进度建议今天学什么 |
| 规划师 | 检查计划是否合理，提出调整建议 |
| 考前教练 | 分析测试成绩和错题，安排针对性练习 |

- 智能体会读取你的进度、题库、计划和错题本，所以回答是针对你的。
- **它不会自己改你的数据。** 要改计划、改题目状态、跳过题、加题时，会出现一张「建议」卡片，你点「确认」才生效，点「忽略」就不改。
- 回复在后台生成，切到别的页面、刷新、甚至关掉窗口再打开，回复都会继续，回来就能看到。
- 生成过程中可以点「停止生成」；对回答不满意可以「重新生成」，也可以换一个模型再问。
- 每条回答下方标明是哪个模型回答的。

## 8. 接入模型

### 添加模型

1. 到「模型」页，选一个预置模板。
2. 填 API Key，点「添加」。
3. 点「测试连接」，确认能用。

| 接口类型 | 预置模板 |
| --- | --- |
| OpenAI 兼容 | DeepSeek、通义千问、Kimi、智谱 GLM、OpenAI，以及 Ollama 等本地模型 |
| Anthropic | Claude |

- 模板里的模型名只是默认值，以服务商控制台为准，可以直接修改。
- 其它兼容 OpenAI 接口的服务，选「自定义」，填接口地址和模型名。

### 按任务指定模型

可以给不同任务分别指定模型，例如讲题用一个、批量导入用便宜的。

| 任务 | 用在哪 |
| --- | --- |
| 问答与讲解 | 学习助教、考前教练、题目页的 AI 按钮 |
| 学习计划 | 规划师 |
| 分类分层 | AI 分类分层 |
| 导入题目 | 从文件里识别题目 |
| 主观题评分 | 简答题评分 |
| 生成课程 | 为新模块生成课程草稿 |

### 用量与对比

- 「模型」页可以看每个模型的调用次数、Token 用量、失败次数。
- 填了单价就会显示估算费用，请以服务商账单为准。
- 「多模型对比」可以把同一个问题发给几个模型，并排看回答和耗时。

### API Key 的安全

- Key 只存在你电脑上的数据库里。
- 界面和接口只显示末尾几位，导出备份时也不包含 Key。

## 9. 导入题目与 AI 分类分层

### 导入

1. 到「题库 → 导入题目」。
2. 上传文件，或直接粘贴文字。支持 `.txt` `.md` `.json` `.csv` `.pdf` `.docx`。
3. 模型把内容拆成一道道题，识别：
   - 题型、选项、答案、解析；
   - 属于哪个模块；
   - 难度层级。
4. **检查后再保存。** 结果先列出来对照：
   - 可以改题名、模块和层级；
   - 有问题的题（缺答案、缺选项等）和题库里已有同名题默认不勾选；
   - 只有勾选的题会写入题库。
5. 模型给出了题库里还没有的模块名称，导入时会自动新建这个模块。
6. 原文没有答案的题，模型不会编造答案。

扫描版 PDF（只有图片没有文字）暂时识别不了，请先用 OCR 软件转成文字。

### AI 分类分层

「题库 → AI 分类分层」让模型判断题目属于哪个模块、哪一层（L1 → L4）和知识点，并给出理由：

- 范围可以选「还没确认过分层的题」「我导入或录入的题」、某一种题型，或全部题目；
- 每次调用处理 10 道题，结果逐条列出和当前分类的对比；
- 点「采用勾选的」或「全部采用」才写入题库；
- 分过类的题会标明是 AI 分的以及理由，随时可以在题目页手动改。

### 手动录题

「题库 → 手动录题」可以一道一道录入，支持全部题型。编程题可以填测试用例。

## 10. 学习资源（视频）

「学习资源」页按关键词搜索学习视频。题目页和课程页也有「找视频」入口，会自动带上知识点。

- 在「设置 → 视频接口」填了 YouTube Data API Key，会直接列出视频。
- B 站、中国大学 MOOC 等平台提供搜索链接，到原网站观看。
- 视频可以收藏到某个模块，之后会出现在那个模块的课程旁边。
- 某个平台搜索失败时，其它平台的结果照常显示。

## 11. 手机和其它电脑

题库、判题和数据都在你的电脑上。手机和其它电脑连过来看到的是同一份数据，在哪做的题都算数。

### 让别的设备连进来

1. 电脑上：「设置 → 设备与互通」，勾选「允许手机连接」。立即生效，不用重新打开程序（从源码运行时，第一次开启需要重新运行 `run.py`）。
2. Windows 电脑：勾选后会自动弹出 Windows 的权限窗口，点「是」，允许 StudyAgent 通过防火墙。没弹出或点了否，可以随时点「允许 StudyAgent 通过防火墙」重来。
3. 同一页的「在手机上填」显示要填的地址，用标着「优先用这个」的那个（例如 `http://192.168.1.20:8765`）。下面几个是 VPN、虚拟机等其它网卡的地址，一般用不上。
4. 手机和电脑连同一个 Wi-Fi。

### 手机上用

| 方式 | 做法 |
| --- | --- |
| 安卓 App | 安装 `StudyAgent.apk`，打开后填电脑的地址，连上后输入访问码（在电脑的「设置 → 设备与互通 → 我的访问码」）。下次打开会自动连上一次的电脑。要换电脑，在「设置 → 设备与互通」点「连接其它电脑」 |
| 不装 App | 手机浏览器打开局域网地址 →「添加到主屏幕」，之后从桌面图标全屏打开 |

### 其它电脑

浏览器打开局域网地址，输入访问码。

### 注意

- 电脑要开着、程序要运行，手机才能用。
- 只在自己家或可信的 Wi-Fi 里打开「允许手机连接」。能拿到访问码的人可以在你电脑上运行编程题代码。不要把端口暴露到公网。

## 12. 学科、模块与多人使用

### 新增学科

平台不只用于编程。在「设置 → 学科与模块」新建学科（例如英语、法考、数学）并填好模块，然后：

1. 在「学习计划」里切换到这个学科；
2. 在「题库 → 导入题目」导入题；
3. 在每个模块里让 AI 生成课程。

新学科默认使用通用的试卷结构：单选 / 判断、多选 / 填空、简答 / 编程三部分。需要别的结构（每部分几道题、什么题型、多少分、多长时间），目前要通过接口修改，见 [技术规范](技术规范.md#考试结构)。

### 模块课程

模块没有课程时，可以点「让 AI 生成课程」，模型按「概念 → 识别信号 → 模板 → 例题 → 易错点 → 小测验」生成草稿，你确认后才发布。

### 多人使用

「设置 → 用户」可以添加用户，每人一个访问码：

- 每个人的进度、错题、计划、测试、对话、模型配置互相独立；
- 平台题库是共享的；
- 访问码丢了，管理员可以重置。

## 13. 备份与迁移

「设置 → 备份与迁移」：

- **导出**：下载一个 JSON 文件，包含你的进度、作答记录、错题、计划、测试、对话和自建题目。不包含模型配置，所以也不包含 API Key。
- **导入**：在新电脑上导入这个文件即可恢复。

也可以直接复制整个数据文件夹（位置见 [第 1 节](#数据存在哪)），复制前先关掉程序。

## 15. 常见问题

**智能体没有反应 / 提示「还没有配置可用的模型」**
到「模型」页添加模型并测试连接。

**测试连接失败**

| 提示 | 处理 |
| --- | --- |
| 认证失败 | 检查 Key 是否复制完整、是否过期 |
| 余额不足 | 到服务商充值 |
| 请求太频繁 | 稍等再试 |
| 超时 / 网络错误 | 检查网络和接口地址；本地模型要先启动 |

**exe 打开后不是独立窗口，而是浏览器**
电脑缺少 WebView2 组件（少数旧版 Windows）。到微软官网下载安装「WebView2 Runtime」，重新打开即可。用浏览器也完全可以正常使用。

**手机连不上电脑**

App 会说明连不上的原因：

| App 的提示 | 原因 | 处理 |
| --- | --- | --- |
| 已经连到电脑了，但……还没开启「允许手机连接」 | 网络是通的，只是开关没开 | 在电脑上勾选「允许手机连接」，再点连接 |
| 这个地址上有程序在响应，但不是 StudyAgent | 地址或端口填错 | 核对电脑上「在手机上填」的地址 |
| 手机连不到这个地址 | 网络不通或被防火墙拦截 | 见下面的检查清单 |

「手机连不到这个地址」时逐项检查：

1. 电脑上 StudyAgent 开着，「允许手机连接」已勾选；
2. 手机和电脑在同一个 Wi-Fi。不要用流量，也不要连路由器的「访客网络」，访客网络会隔离设备；
3. 地址是电脑上标着「优先用这个」的那个，端口号一致；
4. Windows：在 StudyAgent 设置里点「允许 StudyAgent 通过防火墙」，弹窗点「是」。第一次运行时防火墙弹窗如果点了「取消」，Windows 会一直拦截，这一步能修复；
5. 用手机浏览器打开同一个地址：打得开，说明网络没问题；打不开，问题在网络或防火墙；
6. 公司、学校的网络常常禁止设备互相访问。可以让电脑连手机开的热点再试，地址会变，以电脑上新显示的为准。

**编程题提示「没找到函数」**
要定义 `def solve(...)`，或者 `class Solution` 加一个方法，和力扣一样。

**JavaScript 题跑不了**
电脑上安装 [Node.js](https://nodejs.org) 后重新打开程序。

**换电脑怎么保留进度**
见 [第 13 节](#13-备份与迁移)。
